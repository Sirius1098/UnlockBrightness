## 项目简介
UnlockBrightness 是基于 LibXposed API 102 重构的 Xposed 模块，用于拒绝应用强制屏幕亮度.

本项目基于[拒绝强制亮度](https://github.com/Xposed-Modules-Repo/com.fankes.refusebrightness) 进行全套重写，完整源码已开源[UnlockBrightness](https://github.com/Sirius1098/UnlockBrightness)。

感谢 [LSPilot](https://github.com/Xposed-Modules-Repo/me.yun.lspilot) 提供核心逆向思路，DeepSeek‑API 帮助项目开发。
